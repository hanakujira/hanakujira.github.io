四份名單、12 筆資料,合成一張表 —— 我真的跑了一次

這場景你可能很熟:辦一場活動,報名有報名表、群組有記事本、舊系統有一份匯出、
現場又手寫了一張簽到表。四份東西、四種格式,沒有人知道到底來了幾個人。

我用一台「沒有 Excel、沒有安裝任何軟體」的 Windows 電腦,把這件事從頭做了一遍。
這篇記的是結果,還有六個只有真的做過才會遇到的坑。

先看結果

四份來源長這樣:

來源長相
報名表 CSV姓名、電話 0912-345 678、日期 2024/1/5、費用 "1,500"
LINE 記事本Tab 分隔、全形數字 ０９８７－６５４－３２１、沒有 email
舊系統匯出Big5 編碼、欄名 cust_name、日期 20240107、金額 NT$1,500
現場簽到只有名字和金額、全形 １５００

12 筆原始資料,最後是 6 個人。

陳怡君  0912-345-678  yichun@example.com   2024-01-05  1500  報名表 + 舊系統
林志豪  0987-654-321  lin.zh@example.com   2024-01-07  1500  報名表 + LINE + 現場
黃美玲  0933-111-222  meiling@example.com  2024-01-07  1500  報名表 + LINE + 舊系統 + 現場
王建民  0922-333-444  wang44@example.com   2024-01-12  1500  舊系統
小林    0911-222-333                              0          LINE
許雅婷                                             1500       現場

注意最右邊那一欄「來源」——它是我刻意留的。不要刪掉它。
有它在,你才看得出「這個人是四個地方都出現過」還是「只有現場那張紙上有」,
出錯的時候也才追得回去。

三個關鍵決定(比技巧重要)

1. 先決定「什麼叫做同一個人」

整件事只有這一個問題,其餘都是細節。

我的順序是:手機 → Email → 姓名。有手機就用手機當鍵,沒有才退到 Email,
兩個都沒有、只剩名字的,才用名字去對。

但這裡有個地雷:用名字對,遇到同名就完了。 我這份假資料裡,
現場簽到表只有「林志豪」「黃美玲」兩個名字,靠名字對回去了;
如果現場有兩個「陳怡君」,你就會把兩個人的資料黏成一個。

真實資料裡,先問清楚「有沒有第二個欄位可以當鍵」——身分證末三碼、訂單編號、
報名序號,什麼都比名字可靠。

2. 欄位先定好,再開始合

不要一邊合併一邊想欄位。先寫下最終表要有哪幾欄:

姓名 / 手機 / Email / 報名日期 / 費用 / 來源

欄位定了,每個來源的資料就知道該往哪裡倒。反過來做,你會合併到一半發現
「舊系統有『公司名稱』但報名表沒有」,然後整份重來。

3. 格式全部先洗乾淨,再做比對

這一步不做,後面全部白費。

六個我真的踩到的坑

坑 1:金額寫 1,500,用逗號硬切會變成 1 元

第一版我貪快,自己用「逗號」把每一行切開。結果 "1,500" 被切成 1 和 500,
費用欄變成 1 元。而且它不會報錯,就安安靜靜地錯。

正解:用真正的 CSV 解析器,不要自己切字串。CSV 是有一種「用引號包起來、
裡面可以有逗號」的規則的。

這就是為什麼「看起來很簡單」的表格工作會出事:錯的地方不會亮紅燈,
你要自己去看數字對不對。

坑 2:全形數字永遠對不上

０９８７－６５４－３２１ 和 0987-654-321 在你看起來是同一支電話,
在電腦看起來是兩串完全不同的字元。

洗的方式:全形轉半形、只留數字、再照你要的格式重排。洗完之後,
０９８７－６５４－３２１、0987654321、0987 654 321 都會變成 0987-654-321。

坑 3:日期有三種寫法

2024/1/5、20240107、2024-01-05 —— 不統一的話,排序會亂、篩選會漏。
一律轉成 2024-01-07 這種 年-月-日(補零),好處是它照字面排序就等於照時間排序。

坑 4:金額有三種長相

1500、1,500、NT$1,500、１５００。全部只留數字再轉成整數。
不要留小數點和貨幣符號在儲存格裡——那會讓它變成文字,SUM 加不起來。

坑 5:舊系統匯出是 Big5

打開是亂碼的時候,先別急著重打。九成是編碼問題,不是檔案壞了。
指定 Big5 讀就正常了。

坑 6:合併完,還是有 2 個人「不完整」

許雅婷只有現場那張紙上的名字和金額,沒有電話、沒有 Email、沒有日期。
小林有電話但沒有 Email。

這不是失敗,這是真實結果。 硬湊出一個完整的表格才是假的。
合併的真正價值是:把「不知道」的地方圈出來,讓你去問那幾個人。

不寫程式的人怎麼做

上面那些用 Google Sheets 也做得到,不用裝任何東西:

  • IMPORTRANGE —— 把好幾份試算表的資料撈到同一張
  • QUERY —— 用類似 SQL 的寫法篩選、排序
  • 資料透視表 —— 一眼看出重複和缺漏
  • TRIM / PROPER / VALUE —— 洗掉多餘空白、統一大小寫、把文字轉成數字

小量的話,手動也行。但只要來源超過三份、筆數超過一百,手動就一定會錯——
不是你不小心,是這種工作天生就會錯。

一句話總結:表格不是「把資料放進去」,是「先決定什麼叫做同一個人」。

六個坑都真的撞到才寫下來。*
