語法1 表達身份(2:24:57)

  • 句型:N1 は N2 です。= N1 是 N2。
  • 例句:私は高橋です。(わたし たかはし)= 我是高橋。私は学生です。(がくせい)= 我是學生。
  • 注意:は 在這裡唸 wa(助詞讀音)。

語法3 一般疑問(2:31:56)

  • 句型:N1 は N2 ですか。= N1 是 N2 嗎?
  • 答法:はい／ええ、そうです。(是的)/いいえ、ちがいます。医者です。(不,不是。是醫生。)
  • 例句:彼女は教師ですか。→ 她是老師嗎?
  • 單詞:彼女「かのじょ」① 她|教師「きょうし」① 老師|医者「いしゃ」① 醫生

語法4 所有格(2:36:09)

  • 「の」的兩個用法:
    1. 表示所有、所屬,連接兩個名詞,相當於中文的「的」
    2. 連接兩個名詞,不譯(只做連接)
  • 例句:所属 → 中国の人;所有 → 私の本;名詞連接 → 日本語の本、日本語の先生
  • 練習句型:N1 は N2 の N3 です。= N1 是 N2 的 N3。
    これ ⓪ 這、這個|私「わたし」⓪ 我|鞄「かばん」⓪ 包 → 這是我的包。
  • 單詞:人「ひと」⓪ 人|本「ほん」① 書|中国「ちゅうごく」① 中國|日本語「にほんご」⓪ 日語

語法5 表達確認(2:41:06)

  • ね 是終助詞,接在句尾。兩種用法:①徵求對方的贊同或確認 ②輕微的感嘆。
  • 例:①いい天気ですね。(輕微感嘆)②貴方は教師ですね。(向對方確認)③ A:猫は可愛いですね。B:そうですね。
